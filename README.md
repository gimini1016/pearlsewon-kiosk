# 펄세권 키오스크

**디자인팀은 [디자인팀_구현가이드.md](디자인팀_구현가이드.md)부터 확인해 주세요.**

화면별 구성, 색·글꼴, 음료·재료 그림, 받은 피드백과 검수 항목을 한 문서에 모았습니다.

[시연 사이트](https://pearlsewon-kiosk.vercel.app) · [GitHub 저장소](https://github.com/gimini1016/pearlsewon-kiosk)

좋아하는 맛을 고르고 추천 메뉴의 옵션을 다듬는 음료 주문 프로토타입입니다. 제공된 메뉴·옵션·매장 자료를 사용하며, 서버에서는 실제 AI 채팅을 연결합니다. 결제·직원 호출·알림 발송은 시연입니다.

## 로컬 실행

Mac에서는 `run.command`를 실행합니다. 터미널에서는 저장소 루트에서 다음 명령을 사용합니다.

```sh
python3 scripts/build.py
python3 -m backend.server --open
```

주소는 `http://127.0.0.1:8765`입니다. API 키는 서버 환경변수나 로컬 `.env`에만 설정합니다. 키가 없으면 실제 AI 호출을 사용할 수 없습니다. 생성된 HTML을 파일로 직접 열면 버튼과 규칙 기반 시연이 동작합니다.

실행 환경·키 설정·검사·Vercel 배포 방법은 [개발_실행_배포.md](docs/개발_실행_배포.md)에 있습니다. [참고논문_리스트.md](docs/참고논문_리스트.md)는 팀에서 제공한 연구 목록입니다.

## RAG 자료 수정

추가 안내와 확인되지 않은 정보의 응답 기준은 `data/knowledge.json`에서 수정합니다. 메뉴·옵션·표현 사전은 각각의 원본 JSON에서 수정합니다. `data/rag_docs.jsonl`은 직접 편집하지 않고 다음 순서로 생성합니다. 펄 신선도·컵 용량·얼음 예외·좌석 안내도 생성기에 포함됩니다.

```sh
python3 scripts/build_rag_docs.py
python3 scripts/build.py
python3 -m unittest discover -s tests
```

검색은 기존 글자 조각 검색에 상황별 표현 확장과 메뉴 조건 검사를 더합니다. 추천 시 요청한 온도·옵션을 화면 선택까지 유지합니다. 좌석별 점유 상태는 시연의 전체 빈자리 수가 바뀌면 미확인으로 표시합니다. 이 구현 검사는 실제 LLM 응답 품질이나 팀원 평가 질문 전체의 개선 점수를 대신하지 않습니다.

추천·답변 카드·AI 주문은 최종 옵션까지 다시 검사합니다. 우유 제외 요청은 우유가 표기된 메뉴와 밀크폼·치즈폼을 제외하지만 알레르기 안전을 보장하지 않습니다. `3,000원 이하`, `5천원 미만` 같은 명시적 금액 조건은 한 잔 기준이며 사이즈·추가 옵션 가격을 포함합니다. 조건에 맞지 않으면 임의로 조건을 풀어 추천하지 않습니다.

모델 답변의 가격·컵 용량·카페인 수치는 해당 메뉴·사이즈의 원본 값으로 안내합니다. 진함·단맛 등의 비교와 가격을 함께 물으면 요청한 항목을 각각 검증해 안내합니다. 우유 제외에 걸리는 밀크폼·치즈폼은 제외 사유를 별도 안내로 유지합니다.

현재 선택된 메뉴의 사이즈·샷·토핑 등은 모델 기억이 아니라 정규화한 주문 상태로 계산합니다. 명시적으로 해석한 변경 요청은 기존 유료 옵션을 유지한 예상 가격을 만들며, 예산을 넘으면 실제 주문을 바꾸지 않고 금액과 이유를 안내합니다. 가격 문의만으로 옵션을 적용하지 않습니다. 현재·변경 후 계산은 `screen.current_order_quote`로 모델에도 제공합니다.

샷 추가·디카페인 변경 후의 정확한 카페인 함량과 근거가 없는 수량 합계는 확정하지 않습니다. 이 검사는 모든 자연어 주장에 대한 사실 검증을 뜻하지 않으며, 규칙 기반 조건 해석에도 지원하지 않는 표현이 남을 수 있습니다. 답변 완결성의 핵심 회귀 기준은 `tests/answer_checks.py`, 변형 표현·주문 상태 검사는 `tests/test_answer_completeness.py`에 있습니다.
